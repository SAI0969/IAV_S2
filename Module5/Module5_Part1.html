Unit 1 – Introduction to Deep Learning for Computer Vision

1. What is Deep Learning?

Deep Learning (DL) is a subfield of Machine Learning that uses artificial neural networks with multiple layers to automatically learn patterns and features from large amounts of data.

In computer vision, deep learning helps computers understand images and videos.

For example, when identifying a cat, a deep learning model learns:

pbs.org

Raw image

Edges and lines

Textures and shapes

Eyes, ears and face

Cat recognized

The main advantage is that the network learns features automatically instead of requiring humans to define every feature.

2. Artificial Intelligence vs Machine Learning vs Deep Learning

These three concepts are related, but they are not identical.

Artificial Intelligence (AI)

Broadest field

Machine Learning (ML)

Learns patterns from data

Deep Learning (DL)

Uses multi-layer neural networks

  • AI: Develops machines that perform tasks requiring human intelligence, such as reasoning, planning and decision-making.

  • ML: Allows computers to learn patterns from data without explicitly programming every rule.

  • DL: Uses multiple neural network layers to learn complex patterns automatically.

Example: To identify cats:

  • AI: A system that can recognize animals.

  • ML: Learns from labelled cat and dog images.

  • DL: Learns edges, textures, shapes and animal features through multiple neural network layers.

3. Why is Deep Learning important in Computer Vision?

Images contain enormous amounts of information.

A computer must handle variations such as:

  1. Illumination – changes in lighting.

  2. Scale – objects appearing large or small.

  3. Rotation – objects appearing at different angles.

  4. Viewpoint – objects viewed from different directions.

  5. Background – different surroundings.

  6. Occlusion – objects partially hidden.

  7. Deformation – changes in object shape.

  8. Noise – unwanted information in images.

  9. Motion blur – unclear images due to movement.

Traditional methods require manually designed rules for these variations.

Deep learning automatically learns useful representations, making it effective for complex image recognition tasks.

5. What does Deep mean in Deep Learning?

A neural network is called deep when it contains multiple computational layers between input and output.

Simple neural network:

Input → Hidden Layer → Output

Deep neural network:

Input → Hidden Layer 1 → Hidden Layer 2 → Hidden Layer 3 → Hidden Layer 4 → Output

Each layer learns increasingly complex representations.

For example:

  • First layer: Edges.

  • Second layer: Textures.

  • Third layer: Shapes.

  • Fourth layer: Object parts.

  • Final layer: Complete object.

6. Artificial Neural Network (ANN)

An Artificial Neural Network is a computational model inspired by biological neurons.

It consists of interconnected artificial neurons that process information.

A basic neural network has three types of layers:

  1. Input layer – receives input data.

  2. Hidden layer – processes information and learns patterns.

  3. Output layer – produces the final prediction.

Components of a neuron

Input (x): Data received by the neuron.

Weight (w): Determines the importance of an input.

Bias (b): An additional adjustable value that shifts the neuron's output.

Activation function: Determines the final output of the neuron.

The mathematical equation is:

$$ z=\sum_{i=1}^{n}w_ix_i+b $$

The neuron output is:

$$ a=f(z) $$

Where:

  • $x_i$ = input.

  • $w_i$ = weight.

  • $b$ = bias.

  • $f$ = activation function.

  • $a$ = output.

7. Activation Functions

An activation function introduces non-linearity into a neural network.

Without activation functions, multiple layers of linear operations would behave like a single linear transformation. This would limit the network's ability to learn complex relationships.

The important activation functions are:

A. ReLU (Rectified Linear Unit)

ReLU converts negative values into zero and keeps positive values unchanged.

$$ f(x)=\max(0,x) $$

Example:

InputReLU output
-50
-20
00
22
55

Advantages:

  • Simple to calculate.

  • Computationally efficient.

  • Helps reduce vanishing-gradient problems compared with sigmoid and tanh in many deep networks.

B. Sigmoid

Sigmoid converts values into a range between 0 and 1.

$$ \sigma(x)=\frac{1}{1+e^{-x}} $$

Applications:

  • Binary classification.

  • Probability-like output for a binary decision.

Example:

$$ P(\text{Dog})=0.85 $$

This means the model predicts an 85% probability for the Dog class.

C. Tanh

Tanh converts values into a range between -1 and +1.

$$ \tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}} $$

It is zero-centred and can be useful in certain neural network architectures.

D. Softmax

Softmax converts multiple class scores into probabilities whose sum is 1.

$$ P_i=\frac{e^{z_i}}{\sum_j e^{z_j}} $$

Example:

ClassProbability
Cat0.72
Dog0.20
Horse0.08
Total1.00

The model predicts Cat because it has the highest probability.

8. Neural Network Learning Process

A neural network initially contains weights that are initialized with values that are not yet trained.

It learns by repeatedly performing the following operations:

  1. Receives input data.

  2. Produces a prediction.

  3. Compares prediction with the actual answer.

  4. Calculates the error using a loss function.

  5. Calculates gradients using backpropagation.

  6. Updates weights using an optimizer.

  7. Repeats the process.

9. Forward Propagation

Forward propagation is the process of passing input data through the neural network to produce a prediction.

For example:

Input image

Input layer

Hidden layers

Output layer

Prediction: Cat

The output of one layer becomes the input of the next layer.

10. Loss Function

A loss function measures how far the predicted output is from the actual output.

The objective of training is to minimize the loss.

Two important loss functions are:

A. Mean Squared Error (MSE)

Commonly used for regression.

$$ MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2 $$

B. Cross-Entropy Loss

Commonly used for classification.

For multi-class classification:

$$ L=-\sum_{i=1}^{C}y_i\log(\hat y_i) $$

Where:

  • $C$ = number of classes.

  • $y_i$ = actual class value.

  • $\hat y_i$ = predicted probability.

A higher loss generally indicates a worse prediction.

11. Backpropagation

Backpropagation calculates how much each weight contributes to the total loss.

It propagates error information backward through the network and calculates gradients.

Working:

  1. Calculate prediction.

  2. Calculate loss.

  3. Calculate gradients.

  4. Propagate gradients backward.

  5. Update weights.

The derivative:

$$ \frac{\partial L}{\partial w} $$

tells us how the loss changes when a particular weight changes.

12. Gradient Descent

Gradient Descent is an optimization algorithm used to minimize the loss function.

It updates the weights in the direction that reduces the loss.

The formula is:

$$ \boxed{w_{\text{new}}=w_{\text{old}}- \eta\frac{\partial L}{\partial w}} $$

Where:

  • $w$ = weight.

  • $\eta$ = learning rate.

  • $\frac{\partial L}{\partial w}$ = gradient of loss with respect to weight.

Learning rate

Learning rate controls the size of each weight update.

  • Too high: Training may become unstable or overshoot the minimum.

  • Too low: Training becomes very slow.

  • Appropriate: Training can converge more smoothly.

13. Epoch, Batch and Iteration

These three terms are very important for examinations.

14. Image Representation

Computers represent images as numerical values called pixels.

Grayscale image:

A grayscale image contains one channel.

$$ H\times W $$

Pixel values generally range from 0 to 255.

  • 0 = Black.

  • 255 = White.

RGB image:

An RGB image contains three channels:

  • Red.

  • Green.

  • Blue.

Its dimensions are:

$$ H\times W\times 3 $$

Example:

$$ 224\times224\times3 $$

This means 224 pixels in height, 224 pixels in width and 3 colour channels.

15. Why are Fully Connected Networks Not Ideal for Images?

Fully connected networks are not particularly efficient for large images because:

  1. Images contain huge numbers of pixels.

  2. Flattening an image loses its explicit spatial arrangement.

  3. A large number of weights and connections are required.

  4. Nearby pixel relationships are not directly preserved.

This motivates CNNs, which use local connectivity and parameter sharing.

Unit 2 – CNN: Convolutional Neural Network

This document explains CNN in simpler terms and focuses on how a CNN actually understands an image.

1. Basic idea of CNN

A CNN looks at an image in small portions, identifies simple features and combines them to recognize complex objects.

For example, when recognizing a car:

$$ \text{Pixels}\rightarrow\text{Edges}\rightarrow \text{Shapes}\rightarrow\text{Wheels} \rightarrow\text{Car} $$

The network learns these features from training images.

2. CNN Architecture

A basic CNN contains:

  1. Input image.

  2. Convolution layer.

  3. ReLU activation.

  4. Pooling layer.

  5. Additional convolution and pooling layers.

  6. Classification layer.

  7. Output.

v7labs.com

3. Convolution Operation

Convolution is the most important operation in a CNN.

It uses a small matrix called a filter or kernel that moves across the image to detect patterns.

Common filter sizes include:

  • 3 × 3.

  • 5 × 5.

  • 7 × 7.

How convolution works

  1. Place the kernel over a small region of the image.

  2. Multiply corresponding image and kernel values.

  3. Add all multiplication results.

  4. Store the result in the output feature map.

  5. Move the kernel to the next position.

  6. Repeat until the image has been scanned.

Mathematically:

$$ O(i,j)=\sum_m\sum_n I(i+m,j+n)K(m,n) $$

Where:

  • $I$ = input image.

  • $K$ = kernel.

  • $O$ = output feature map.

The exact operation in CNN implementations is commonly cross-correlation, although it is often called convolution.

4. Filters and Kernels

A filter is a small matrix used to identify particular visual patterns.

Examples:

FilterDetects
Vertical edge filterVertical edges
Horizontal edge filterHorizontal edges
Diagonal edge filterDiagonal edges
Texture filterTexture patterns

The important point is that CNNs learn their filters during training instead of requiring humans to manually specify all the filters.

5. Feature Map

A feature map is the output produced after applying a filter to an image.

Example:

$$ \text{Original Image} \rightarrow \text{Filter} \rightarrow \text{Feature Map} $$

It indicates where a particular feature or pattern is detected.

A CNN can generate multiple feature maps using different filters.

6. ReLU Activation

After convolution, ReLU is commonly applied.

$$ ReLU(x)=\max(0,x) $$

Example:

InputOutput

-10

It introduces non-linearity and helps the network learn complex patterns.

7. Pooling Layer

Pooling reduces the spatial dimensions of feature maps.

Its purpose is to:

  • Reduce computation.

  • Reduce memory requirements.

  • Retain important features.

  • Provide some tolerance to small image shifts.

Two common pooling techniques are:

A. Max Pooling

Selects the maximum value from a particular region.

Example:

Input feature map

1 3

2 4

2 × 2 region

Maximum = 4

B. Average Pooling

Calculates the average of the values in a particular region.

$$ Average=\frac{\text{Sum of values}}{\text{Number of values}} $$

Example:

$$ \frac{1+3+2+4}{4}=2.5 $$

Max Pooling vs Average Pooling

Max PoolingAverage Pooling

8. Multiple CNN Layers and Feature Hierarchy

CNNs learn features at different levels.

LayerFeatures learned
Early layersEdges, lines, corners
Middle layersCurves, textures, simple shapes
Deeper layersEyes, ears, wheels, faces
Final layersComplete objects such as cats, dogs and cars

This is called hierarchical feature learning.

9. How does CNN learn?

Suppose we want to classify cats and dogs.

Training process:

  1. Give the CNN labelled cat and dog images.

  2. CNN extracts features using convolution.

  3. It produces a prediction.

  4. Compare prediction with the actual label.

  5. Calculate loss.

  6. Perform backpropagation.

  7. Update weights and filters.

  8. Repeat until the model improves.

Example:

$$ P(\text{Cat})=0.95 $$
$$ P(\text{Dog})=0.05 $$

The model predicts Cat.

10. Why CNN instead of a Normal Neural Network?

Three important concepts explain why CNNs are suitable for images.

Local connectivity: A filter looks at a small region of the image rather than connecting every input pixel to every neuron.

Parameter sharing: The same filter is reused across different locations in the image, reducing the number of learnable parameters.

Spatial structure: CNNs preserve spatial relationships between nearby pixels through feature maps.

These properties make CNNs effective for image processing.

  2. Object detection.

  3. Image segmentation.

  4. Face recognition.

  5. Medical image analysis.

  6. Handwritten character recognition.

  7. Autonomous vehicles.

Unit 3 – CNN Training and Optimization (Document 5.3)

This topic explains how a CNN learns from images, reduces prediction errors and improves its performance.

1. What is CNN Training?

CNN training is the process of teaching a CNN to make correct predictions using labelled training images.

Example:

InputCorrect answer
Cat imageCat
Dog imageDog
Cat imageCat
Dog imageDog

Initially, the CNN may predict incorrectly. It gradually improves by calculating errors and updating its parameters.

2. What does a CNN actually learn?

A CNN does not simply store training images. It learns important features.

  • Early layers: Edges, lines, corners and textures.

  • Middle layers: Eyes, ears, nose and fur patterns.

  • Deeper layers: Cat faces, dog faces and overall body shapes.

Therefore:

$$ \text{Simple Features}\rightarrow \text{Complex Features}\rightarrow \text{Object Recognition} $$

3. What are Parameters?

Parameters are the learnable values inside a CNN.

Two important parameters are:

Weights: Determine the importance of different input features.

Biases: Allow the network to adjust the output independently of the weighted input.

During training, these parameters are updated to improve predictions.

Remember:

  • Parameters are learned from training data.

  • Hyperparameters are selected before or during model development.

6. Forward Propagation

Forward propagation means passing the input image through the CNN to obtain a prediction.

The image passes through:

  1. Convolution.

  2. Activation.

  3. Pooling.

  4. Additional convolution layers.

  5. Fully connected layer.

  6. Output layer.

Example

Suppose the CNN receives an image of a cat.

It predicts:

ClassProbability
Cat0.30
Dog0.70

The CNN predicts Dog.

But the actual answer is Cat.

Therefore, the prediction is incorrect and the CNN must improve.

7. Loss Calculation

Loss measures the difference between the actual answer and predicted answer.

  • Small loss = Better prediction.

  • Large loss = Poor prediction.

Example:

Before training:

ClassProbability
Cat0.30
Dog0.70

After training:

ClassProbability
Cat0.90
Dog0.10

The model has improved its prediction for the cat image.

Cross-Entropy Loss

Cross-entropy is commonly used for classification problems.

$$ L=-\sum_{i=1}^{C}y_i\log(\hat y_i) $$

Where:

  • $y_i$ = actual label.

  • $\hat y_i$ = predicted probability.

  • $C$ = number of classes.

It penalizes incorrect predictions, especially when the model assigns a low probability to the correct class.

8. Backpropagation

Backpropagation determines how the model's parameters contributed to the prediction error.

It works backward from the output layer towards the earlier layers.

Steps:

  1. Calculate prediction.

  2. Calculate loss.

  3. Calculate gradients.

  4. Propagate gradients backward.

  5. Determine how weights should change.

Important: Backpropagation calculates gradients; the optimizer uses those gradients to update the parameters.

9. What is a Gradient?

A gradient indicates the direction and rate at which the loss changes with respect to a parameter.

$$ \frac{\partial L}{\partial w} $$

It helps determine how a weight should change to reduce the loss.

Think of walking down a hill:

  • The height represents loss.

  • The slope represents the gradient.

  • Moving downhill represents minimizing the loss.

10. Updating Weights

Once gradients are calculated, the optimizer updates the weights.

The formula is:

$$ \boxed{w_{\text{new}}=w_{\text{old}}-\eta \frac{\partial L}{\partial w}} $$

Where:

  • $w_{\text{new}}$ = new weight.

  • $w_{\text{old}}$ = old weight.

  • $\eta$ = learning rate.

  • $\frac{\partial L}{\partial w}$ = gradient.

Solved example

Given:

  • Old weight = 0.50.

  • Gradient = 0.20.

  • Learning rate = 0.10.

Formula to use:

$$ w_{\text{new}}=w_{\text{old}}-\eta g $$

Why? Because we need to update the weight using its gradient and learning rate.

Substitute:

$$ w_{\text{new}}=0.50-(0.10\times0.20) $$
$$ =0.50-0.02 $$
Final answer: 0.48

The weight changes from 0.50 to 0.48.

11. Learning Rate

Learning rate determines how much the weights change during each optimization step.

Learning rateEffect
Too highMay overshoot the minimum and become unstable
Too lowTraining becomes very slow
AppropriateAllows smoother optimization

It is an important hyperparameter in CNN training.

12. Epoch, Batch and Iteration

These are frequently asked examination questions.

Epoch: One complete pass through the entire training dataset.

Batch: A group of images processed together.

Iteration: One parameter-update step based on a batch.

Solved example

Given:

  • Dataset = 1,000 images.

  • Batch size = 100.

Formula:

$$ \text{Iterations per epoch} =\frac{\text{Total images}}{\text{Batch size}} $$

Substitute:

$$ =\frac{1000}{100}=10 $$

Therefore:

  • One batch contains 100 images.

  • One iteration processes one batch and updates parameters.

  • Ten iterations complete one epoch.

13. Mini-Batch Training

Mini-batch training divides the training dataset into smaller groups.

Example:

  • Total images = 10,000.

  • Batch size = 32.

The CNN processes 32 images at a time.

For each batch:

  1. Forward propagation.

  2. Loss calculation.

  3. Backpropagation.

  4. Weight update.

It then processes the next batch until the complete dataset has been processed.

This is repeated across multiple epochs.

14. Optimizers

An optimizer determines how the CNN's weights and biases should be updated to reduce loss.

Important optimizers in your document:

A. Gradient Descent

Gradient Descent minimizes the loss by updating parameters in the negative gradient direction.

$$ w_{\text{new}}=w_{\text{old}}-\eta\nabla L $$

B. Stochastic Gradient Descent (SGD)

SGD updates model parameters using gradients calculated from individual training examples or small batches, depending on the implementation.

It performs repeated updates and can be computationally efficient.

C. Momentum

Momentum uses information from previous gradients to influence current updates.

It helps accelerate optimization in consistent directions and reduce oscillations.

D. RMSProp

RMSProp adjusts the learning rate for individual parameters using a moving average of squared gradients.

This helps adapt the update sizes during training.

E. Adam Optimizer

Adam stands for Adaptive Moment Estimation.

It combines information from:

  • First moment: Moving average of gradients.

  • Second moment: Moving average of squared gradients.

It adaptively adjusts parameter updates.

It is a popular optimizer for training deep neural networks.

Comparison

SGDUses sample or mini-batch gradients
MomentumUses previous gradient information
RMSPropAdapts updates using squared gradients
AdamCombines first- and second-moment estimates

$$ Accuracy=\frac{90}{100}\times100=90\% $$

Ideally, as training progresses:

However, training accuracy alone cannot tell us whether the model performs well on unseen images.

Unit 4 – Transfer Learning (Document 5.4)

1. Introduction to Transfer Learning

Training a deep CNN from scratch can require:

  1. Large datasets.

  2. Powerful GPUs.

  3. Significant training time.

  4. Careful hyperparameter tuning.

But sometimes we have only a small dataset.

For example, suppose we want to classify plant leaves as healthy or diseased. We may not have thousands of labelled leaf images.

Instead of training a new CNN from zero, we can use a CNN already trained on a large image dataset.

This is called Transfer Learning.

2. What is Transfer Learning?

Transfer Learning is the process of using knowledge learned from one task or dataset to solve another related task.

In computer vision, we reuse the visual features learned by a pre-trained CNN for a new image-recognition problem.

Example:

Large image dataset

Pre-trained CNN

Learned visual features

New plant-leaf dataset

Healthy / Diseased

Real-life analogy

Imagine a student who already knows mathematics and algebra.

When learning machine learning, the student does not need to start learning basic mathematics again.

Previous knowledge helps with the new subject.

Transfer learning works similarly.

3. What is a Pre-trained Model?

A pre-trained model is a neural network that has already been trained on a large dataset.

It has learned useful visual patterns such as:

  • Edges.

  • Corners.

  • Shapes.

  • Textures.

  • Object parts.

Important pre-trained CNN architectures:

VGG

Deep architecture using small convolution filters.

ResNet

Uses residual connections to support very deep networks.

Inception

Processes features at multiple spatial scales.

MobileNet

Designed for efficient computation on mobile and resource-constrained devices.

EfficientNet

Uses compound scaling of network depth, width and resolution.

4. Without Transfer Learning vs With Transfer Learning

Suppose we want to classify healthy and diseased leaves.

Without Transfer Learning:

  1. Collect a large dataset.

  2. Initialize a CNN with random weights.

  3. Train the entire CNN.

  4. Learn edges.

  5. Learn shapes.

  6. Learn textures.

  7. Learn leaf-specific features.

  8. Build a classifier.

This requires more data and computation.

With Transfer Learning:

  1. Select a pre-trained CNN.

  2. Reuse the learned features.

  3. Adapt the final classifier.

  4. Train on leaf images.

  5. Predict healthy or diseased.

This generally requires less training time and data.

Important concept: Early layers learn general features, whereas deeper layers learn more task-specific features.

7. Feature Extraction

Feature extraction is a transfer learning technique in which we use a pre-trained CNN to extract useful features.

The existing CNN layers are kept fixed, and only the new classifier is trained.

Example:

$$ \text{Image}\rightarrow\text{Pre-trained CNN} $$
$$ \rightarrow\text{Extracted Features} \rightarrow\text{New Classifier} \rightarrow\text{Prediction} $$

Advantages

  1. Faster training.

  2. Requires fewer trainable parameters.

  3. Useful for small datasets.

  4. Reduces computational requirements.

  5. Lower risk of overfitting compared with training many layers on a small dataset.

8. Freezing Layers

Freezing means preventing selected layers from updating their parameters during training.

Example:

LayerStatus
Conv 1Frozen
Conv 2Frozen
Conv 3Frozen
Conv 4Frozen
ClassifierTrainable

Only the new classifier is trained.

Why do we freeze layers?

The pre-trained model already knows useful features such as edges, corners and basic textures.

There is no need to relearn these features from the beginning.

Freezing reduces:

  • Training time.

  • Computation.

  • Number of trainable parameters.

It is particularly useful when the new dataset is small.

9. Fine-Tuning

Fine-tuning is another transfer learning technique.

Here, we allow some of the pre-trained CNN layers to update using the new dataset.

Example:

LayerStatus
Conv 1Frozen
Conv 2Frozen
Conv 3Trainable
Conv 4Trainable
ClassifierTrainable

This allows the network to adapt its previously learned features to the new task.

Fine-tuning generally uses a small learning rate to avoid drastically changing the pre-trained weights.

11. When Should We Use Feature Extraction?

Use feature extraction when:

  1. The new dataset is small.

  2. The new task is similar to the original task.

  3. Faster training is required.

  4. Fewer trainable parameters are preferred.

Example: A model trained on general photographs is used to classify different animal species.

12. When Should We Use Fine-Tuning?

Use fine-tuning when:

  1. The new dataset is reasonably large.

  2. The new task is somewhat different.

  3. Existing features need adjustment.

  4. Better task-specific performance is required.

Example: A model trained on ordinary photographs is adapted to a specialized medical-image classification task.

Step 2: Load pre-trained weights

Step 3: Remove original classification layer

Step 4: Add new classifier

Step 5: Freeze selected layers

Step 8: Fine-tune the model

14. Advantages and Limitations of Transfer Learning

Advantages

  • Reduces training time.

  • Requires fewer training images in many cases.

  • Reduces computational cost.

  • Reuses useful visual features.

  • Helps when training data is limited.

Limitations

  • A pre-trained model may not suit the new domain.

  • Incorrectly chosen models may perform poorly.

  • Fine-tuning can cause overfitting.

  • Different input preprocessing requirements may exist.

  • A model may retain biases from its original dataset.

After ReLU:

15. Output Layer

The output layer depends on the type of classification problem.

There are three important types.

A. Binary Classification

Binary classification involves two classes.

Example:

  • Cat.

  • Dog.

Usually, sigmoid activation is used.

$$ \sigma(x)=\frac{1}{1+e^{-x}} $$

Example:

$$ P(\text{Dog})=0.87 $$

The model predicts Dog, assuming the classification threshold is 0.5.

B. Multi-Class Classification

Multi-class classification involves more than two classes, but each image belongs to only one class.

Example:

  • Cat.

  • Dog.

  • Horse.

Softmax is generally used.

$$ P_i=\frac{e^{z_i}}{\sum_j e^{z_j}} $$

The resulting probabilities sum to 1.

Softmax numerical example

Suppose the logits are:

  • Cat = 1.

  • Dog = 2.

  • Horse = 0.

Formula:

$$ P_i=\frac{e^{z_i}}{\sum_j e^{z_j}} $$

First calculate:

$$ e^1=2.718,\quad e^2=7.389,\quad e^0=1 $$

Sum:

$$ 2.718+7.389+1=11.107 $$

Probabilities:

$$ P(Cat)=\frac{2.718}{11.107}=0.245 $$
$$ P(Dog)=\frac{7.389}{11.107}=0.665 $$
$$ P(Horse)=\frac{1}{11.107}=0.090 $$
Prediction: Dog

19. Classification Evaluation Metrics

Four important evaluation metrics are Accuracy, Precision, Recall and F1-score.

A. Accuracy

Accuracy measures the proportion of all predictions that are correct.

$$ \boxed{Accuracy=\frac{TP+TN}{TP+TN+FP+FN}} $$

B. Precision

Precision measures how many predicted positive cases are actually positive.

$$ \boxed{Precision=\frac{TP}{TP+FP}} $$

High precision means fewer false positives.

C. Recall

Recall measures how many actual positive cases are correctly identified.

$$ \boxed{Recall=\frac{TP}{TP+FN}} $$

High recall means fewer false negatives.

D. F1-Score

F1-score is the harmonic mean of precision and recall.

$$ \boxed{F1=2\times\frac{Precision\times Recall} {Precision+Recall}} $$

It is particularly useful for imbalanced datasets.

20. Solved Numerical Example – Evaluation Metrics

Suppose a disease detection model produces:

  • TP = 80.

  • TN = 70.

  • FP = 10.

  • FN = 20.

Step 1: Calculate Accuracy

Formula:

$$ Accuracy=\frac{TP+TN}{TP+TN+FP+FN} $$

Substitute:

$$ =\frac{80+70}{80+70+10+20} $$
$$ =\frac{150}{180}\times100 $$
$$ \boxed{Accuracy=83.33\%} $$

Step 2: Calculate Precision

$$ Precision=\frac{TP}{TP+FP} $$
$$ =\frac{80}{80+10} =\frac{80}{90} $$
$$ \boxed{Precision=88.89\%} $$

Step 3: Calculate Recall

$$ Recall=\frac{TP}{TP+FN} $$
$$ =\frac{80}{80+20} =\frac{80}{100} $$
$$ \boxed{Recall=80\%} $$

Step 4: Calculate F1-Score

$$ F1=2\times\frac{P\times R}{P+R} $$
$$ =2\times\frac{0.8889\times0.80}{0.8889+0.80} $$
$$ \boxed{F1\approx84.21\%} $$

25. Image Classification Using Transfer Learning

Instead of training an entire CNN from scratch, we can use a pre-trained model.

Examples:

  • VGG.

  • ResNet.

  • Inception.

  • MobileNet.

  • EfficientNet.

Steps:

  1. Select a pre-trained CNN.

  2. Load pre-trained weights.

  3. Replace the original classification layer.

  4. Add a new classifier.

  5. Freeze the pre-trained layers.

  6. Train the new classifier.

  7. Optionally fine-tune selected layers.

This is useful when the target dataset is small or training resources are limited.
