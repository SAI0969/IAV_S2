5.6 – Object Detection Using R-CNN

1. What is Object Detection?

Object detection is the process of identifying:

  1. What objects are present in an image.

  2. Where those objects are located.

It provides:

  • Object class (Car, Dog, Person).

  • Object location.

  • Bounding box.

  • Confidence score.

Example: If an image contains two cars and one person, an object detector identifies all three and draws separate bounding boxes around them.

2. Image Classification vs Object Detection

Image ClassificationObject Detection
Identifies the main classIdentifies multiple objects
Gives class labelGives class and location
No bounding box requiredUses bounding boxes
Example: DogExample: Dog at a particular location

Remember:

  • Classification → What is in the image?

  • Detection → What is present and where is it?

3. Challenges in Object Detection

Object detection is more difficult because of:

  1. Multiple objects – many objects may appear together.

  2. Different sizes – objects may be large or very small.

  3. Different positions – objects can appear anywhere.

  4. Scale variation – the same object appears at different sizes.

  5. Occlusion – one object partially hides another.

  6. Background complexity – objects may appear against complicated backgrounds.

4. Bounding Box

A bounding box is a rectangular box drawn around an object to indicate its location.

It is represented using:

$$ (x_1,y_1,x_2,y_2) $$

Where:

  • $x_1,y_1$ = top-left coordinates.

  • $x_2,y_2$ = bottom-right coordinates.

medium.com

A bounding box identifies the object's location, not its exact shape.

5. What is R-CNN?

R-CNN stands for Regions with Convolutional Neural Networks.

It is a deep-learning-based object detection method.

Its main idea is:

Instead of applying a CNN to the entire image only once, R-CNN first generates possible object regions and then applies a CNN to each region.

6. Main Components of R-CNN

There are three major components.

1. Region Proposal Generation

Finds possible regions that may contain objects.

2. CNN Feature Extraction

Extracts important visual features from each region.

3. Classification and Bounding Box Regression

  • Classification determines what object is present.

  • Regression adjusts the bounding box to fit the object more accurately.

7. Selective Search

Selective Search is a traditional computer vision technique used in original R-CNN to generate region proposals.

It groups visually similar regions using:

  • Colour

  • Texture

  • Size

  • Shape

  • Spatial similarity

For example, an image containing a car and a person may generate approximately 2,000 candidate regions.

These are possible object locations, not confirmed detections.

8. Complete R-CNN Architecture

Input ImageSelective SearchRegion Proposals (e.g. 2000)Crop and Resize Each RegionCNN Feature Extraction

SVM

Object classification

Regression

Box refinement

NMS – Remove Duplicate BoxesFinal Detected Objects

Step-by-step working

  1. Input image is given to the system.

  2. Selective Search generates region proposals.

  3. Each proposal is cropped and resized to a fixed size.

  4. CNN extracts features from each region.

  5. SVM classifies each region into an object class.

  6. Bounding box regression improves the predicted location.

  7. NMS removes duplicate detections.

  8. Final detected objects are produced.

9. CNN Feature Extraction

CNN extracts important visual information from the image.

  • Early layers: edges, lines and corners.

  • Middle layers: textures, shapes and object parts.

  • Deep layers: semantic features such as car, person and dog.

The output is a feature vector representing the region.

10. Object Classification Using SVM

SVM stands for Support Vector Machine.

Original R-CNN uses class-specific SVM classifiers to identify the object represented by the CNN feature vector.

Example:

  • Car classifier → Car

  • Person classifier → Person

  • Dog classifier → Dog

11. Bounding Box Regression

The proposed bounding box may not accurately surround the object.

Bounding box regression learns to adjust the box by changing its position and dimensions.

For example:

  • Initial box is too large.

  • Regression shifts the coordinates and reduces its size.

  • Final box fits the object better.

12. Intersection over Union (IoU)

IoU measures the overlap between a predicted bounding box and the ground-truth bounding box.

Formula:

$$ IoU=\frac{\text{Area of Intersection}} {\text{Area of Union}} $$

Example:

  • Intersection area = 80

  • Union area = 100

$$ IoU=\frac{80}{100}=0.8 $$
$$ IoU=80\% $$
mjrovai.github.io

Higher IoU means better overlap.

13. Non-Maximum Suppression (NMS)

NMS removes duplicate bounding boxes that identify the same object.

Steps:

  1. Sort detections according to confidence score.

  2. Select the box with the highest confidence.

  3. Calculate IoU with the remaining boxes.

  4. Suppress boxes having excessive overlap.

  5. Repeat until the remaining detections are processed.

Example:

DetectionConfidence
Car A95%
Car B89%
Car C72%

If A and B overlap significantly and represent the same car, NMS retains A and suppresses B, depending on the IoU threshold.

14. Training and Inference

Training:

  1. Prepare labelled images.

  2. Generate region proposals.

  3. Extract CNN features.

  4. Train class-specific SVM classifiers.

  5. Train bounding-box regressors.

Inference (testing):

  1. Give an image.

  2. Generate region proposals.

  3. Crop and resize.

  4. Extract CNN features.

  5. Predict object classes.

  6. Refine bounding boxes.

  7. Apply NMS.

  8. Produce final detections.

15. Evolution of R-CNN

16. Advantages and Limitations

Advantages

  • Good detection accuracy.

  • Uses powerful CNN features.

  • Detects and localizes multiple objects.

  • Flexible for different detection tasks.

Limitations

  • Slow because many regions are processed separately.

  • Requires large storage for features.

  • Multi-stage training is complicated.

  • Original R-CNN is unsuitable for many real-time applications.

Applications: Autonomous vehicles, surveillance, healthcare, agriculture, retail and manufacturing.

5.7 – Object Detection Using YOLO

1. What is YOLO?

YOLO stands for You Only Look Once.

It is a deep-learning-based object detection approach that detects objects using one integrated prediction process.

Its central idea is:

The entire image is processed by a neural network in one forward pass to predict object classes and bounding boxes.

2. Why Do We Need YOLO?

Original R-CNN processes many region proposals separately.

This requires many CNN computations and makes detection slow.

YOLO solves this problem by predicting objects directly from the complete image using a single integrated network.

3. One-Stage vs Two-Stage Detection

5. Grid-Based Object Detection

In the original YOLO formulation, the image is divided into a grid.

Each grid cell is responsible for predicting objects whose centre lies inside that cell.

chih-sheng-huang821.medium.com

Why use a grid?

It provides a structured way to predict object locations across the image.

For example, if the centre of a car is inside a particular cell, that cell becomes responsible for predicting the car.

Note: This grid explanation describes the original YOLO formulation; later YOLO versions use different detection-head designs.

6. Bounding Box Prediction

YOLO predicts the bounding box using four values:

$$ (x,y,w,h) $$

Where:

  • $x$ = horizontal centre position.

  • $y$ = vertical centre position.

  • $w$ = width.

  • $h$ = height.

These values describe the object's position and dimensions.

7. Confidence Score

Confidence represents how strongly the model believes that:

  • An object is present.

  • The predicted box corresponds to an object.

Example:

$$ \text{Car confidence}=0.92 $$

This indicates a high-confidence detection.

8. Class Prediction

YOLO also predicts the class of the detected object.

Example:

ClassClass score
Person0.05
Car0.85
Dog0.03
Bicycle0.07

The highest class score is Car.

A complete detection contains:

$$ \text{Bounding Box}+\text{Confidence}+\text{Class} $$

9. Normalized Coordinates

Coordinates can be represented relative to the image dimensions.

Their values generally lie between 0 and 1.

For example:

  • $x=0.5$: horizontal centre is halfway across the image.

  • $y=0.5$: vertical centre is halfway down the image.

This makes coordinate representation independent of absolute image size.

10. Multiple Object Detection

YOLO can detect several objects in the same image.

Example:

  • Person

  • Car

  • Dog

  • Bicycle

However, early grid-based YOLO had limitations when multiple object centres appeared in the same cell, especially for small and closely positioned objects.

Later generations introduced improvements to handle these cases.

11. IoU

IoU measures the overlap between predicted and ground-truth bounding boxes.

$$ IoU=\frac{Intersection}{Union} $$

Example:

$$ IoU=\frac{80}{100}=0.8=80\% $$

Higher IoU indicates better localization.

Important distinction:

  • Confidence → How confident is the detection?

  • IoU → How accurately do the boxes overlap?

12. Non-Maximum Suppression

YOLO may predict several overlapping boxes for the same object.

NMS removes redundant detections.

Steps:

  1. Sort boxes by confidence.

  2. Select the highest-confidence box.

  3. Calculate IoU with other boxes.

  4. Suppress boxes whose overlap exceeds the threshold.

  5. Repeat.

13. YOLO Loss Function

YOLO learns to predict accurate bounding boxes, object confidence and class probabilities.

Its loss conceptually combines:

  1. Localization loss – measures bounding-box position and size errors.

  2. Confidence/objectness loss – measures errors in object-presence confidence.

  3. Classification loss – measures errors in class prediction.

The model adjusts its parameters during training to reduce the overall loss.

The exact loss formulation varies between YOLO versions.

14. YOLO Training and Inference

Training:

  1. Collect labelled images.

  2. Resize and preprocess images.

  3. Provide ground-truth bounding boxes and classes.

  4. Perform forward propagation.

  5. Calculate prediction errors using the loss function.

  6. Update model weights using backpropagation and optimization.

Inference:

  1. Give a new image.

  2. Perform one network forward pass.

  3. Predict bounding boxes, confidence and classes.

  4. Remove low-confidence predictions.

  5. Apply NMS.

  6. Produce final detections.

16. Advantages, Limitations and Applications

Advantages

  • Fast object detection.

  • Detects multiple objects.

  • Processes the complete image.

  • Suitable for real-time applications.

Limitations

  • Small objects can be difficult to detect.

  • Closely located objects can be challenging.

  • Localization may be less accurate in some situations than region-based approaches.

Applications

  • Autonomous driving.

  • CCTV surveillance.

  • Agriculture.

  • Manufacturing.

  • Sports analysis.

  • Robotics.

5.8 – Video Analysis Using 3D CNNs

1. Introduction to Video Analysis

A video is a sequence of images called frames, captured over time.

Example:

Person standing → Person raising hand → Person waving → Person lowering hand.

Each frame contains spatial information, while the complete sequence contains temporal information.

Therefore:

  • Image analysis → Understands what is present in one image.

  • Video analysis → Understands what is happening across multiple frames.

2. What is Video Analysis?

Video analysis is the process of extracting meaningful information from a sequence of video frames.

It can identify:

  • Objects present in a video.

  • Object movements.

  • Human activities.

  • Abnormal activities.

  • Events occurring over time.

Examples: walking, running, jumping, swimming, fighting and falling.

3. Why is Video Analysis More Difficult Than Image Analysis?

An image contains:

$$ Height \times Width \times Channels $$

A video contains:

$$ Time \times Height \times Width \times Channels $$

For example:

$$ 16 \times 112 \times 112 \times 3 $$

This means:

  • 16 frames.

  • Each frame has 112 × 112 pixels.

  • 3 colour channels (RGB).

Video analysis is more difficult because it must understand both image content and changes across time.

4. Spatial Information

Spatial information describes what is present in an individual frame.

Examples:

  • Person

  • Car

  • Ball

  • Building

  • Tree

A conventional CNN is effective at extracting spatial features.

5. Temporal Information

Temporal information describes how the content changes over time.

Example:

Frame 1 → Person standing

Frame 2 → Person moving

Frame 3 → Person running

Frame 4 → Person falling

The sequence provides information about movement and actions.

Remember this distinction

Spatial

What is present?

Person, car, ball

Temporal

How does it change?

Walking, running, falling

6. Why is 2D CNN Not Sufficient for Video?

A conventional 2D CNN performs convolution over:

  • Height

  • Width

It processes spatial information in an image but does not directly learn motion across time.

For example, if we provide four frames separately to a 2D CNN, it can recognize the person in each frame, but it does not inherently model the movement sequence.

Therefore, we use 3D convolution to learn relationships across frames.

7. What is a 3D CNN?

A 3D CNN stands for Three-Dimensional Convolutional Neural Network.

It is a neural network that performs convolution across three dimensions:

  1. Height

  2. Width

  3. Time

Unlike a 2D CNN, a 3D CNN can process multiple consecutive video frames together.

$$ 3D\ CNN = Time + Height + Width $$

It learns spatial features and temporal patterns jointly.

9. Understanding 3D Convolution

2D Convolution:

A 2D filter moves across an image horizontally and vertically.

3D Convolution:

A 3D filter moves across:

  • Horizontally.

  • Vertically.

  • Temporally (across video frames).

cameronrwolfe.substack.com

Example:

Suppose a video contains 16 frames.

$$ 16 \times 112 \times 112 \times 3 $$

A conceptual 3D filter may have dimensions:

$$ 3 \times 3 \times 3 $$

Where:

  • First 3 = temporal depth.

  • Second 3 = height.

  • Third 3 = width.

It observes a small spatial region across three consecutive frames and learns motion-related patterns.

10. What Does a 3D CNN Learn?

Different layers learn different types of features.

LayerFeatures learned
Early layersEdges, textures and simple motion
Middle layersBody-part movements and direction
Deep layersWalking, running, jumping, swimming

The learning process can be represented as:

$$ Pixels + Frames $$
$$ \downarrow $$
$$ Spatial\ Features $$
$$ \downarrow $$
$$ Motion\ Patterns $$
$$ \downarrow $$
$$ Action/Event $$

11. Spatio-Temporal Learning

Spatio-temporal means combining:

  • Spatial = Where things are.

  • Temporal = How things change with time.

Example: Running.

  • Frame 1: Left leg forward.

  • Frame 2: Right leg forward.

  • Frame 3: Left leg forward.

  • Frame 4: Right leg forward.

An individual frame may not be enough to identify running. The sequence of movements reveals the action.

This is called spatio-temporal learning.

12. Video Representation

A video is represented as a tensor:

$$ T \times H \times W \times C $$

Where:

  • T = Number of frames.

  • H = Height.

  • W = Width.

  • C = Number of colour channels.

Example:

$$ 16 \times 112 \times 112 \times 3 $$

Represents 16 RGB frames, each with a resolution of 112 × 112.

13. Why Do We Use Video Clips?

Processing an entire long video at once is computationally expensive.

Therefore, videos are divided into smaller clips.

Before providing video to a 3D CNN, preprocessing is required.

Frame Extraction: Extract individual frames from the video.

Frame Sampling: Select only some frames instead of processing every frame. For example, select 16 frames from a 300-frame video.

Resizing: Convert frames to a common resolution.

Normalization: Scale pixel values to a suitable numerical range.

Clip Creation: Group selected frames into smaller video clips.

15. 3D Pooling

Pooling reduces the dimensions of feature maps and helps reduce computational requirements.

In 3D CNNs, pooling operates across three dimensions:

  • Time

  • Height

  • Width

It reduces feature-map size while retaining important information.

For example, a 3D max-pooling operation selects the maximum value within a small 3D region.

Working

  1. Input video is divided into clips.

  2. Frames are sampled and preprocessed.

  3. 3D convolution extracts spatial and temporal features.

  4. ReLU introduces non-linearity.

  5. 3D pooling reduces feature dimensions.

  6. Fully connected layers combine learned features.

  7. Classification predicts the action.

17. Applications

  • Surveillance – Detect fighting, falling and intrusion.

  • Sports – Identify player movements and game events.

  • Healthcare – Fall detection, gait analysis and rehabilitation monitoring.

  • Autonomous systems – Pedestrian behaviour and traffic events.

  • Video classification – Identify activities in video clips.

18. Advantages and Limitations

Advantages

  1. Learns spatial and temporal features jointly.

  2. Suitable for video processing.

  3. Automatically extracts features.

  4. Supports end-to-end learning.

  5. Effective for local motion patterns.

Limitations

  1. High computational cost.

  2. Large memory requirements.

  3. Expensive training.

  4. Requires labelled video datasets.

  5. Standard short-clip models may struggle with very long-term temporal relationships.

Important additional concept – Receptive Field:

The receptive field is the portion of the input that influences a particular feature.

In a 3D CNN, it represents a spatio-temporal region.

For example:

$$ 3\ frames \times 5 \times 5\ pixels $$

means that a feature can depend on a 5 × 5 spatial region across three frames.

5.9 – Action Recognition Using RNN

1. Introduction to Action Recognition

Action recognition is the process of identifying an activity being performed in a video.

Examples:

  • Walking

  • Running

  • Jumping

  • Swimming

  • Clapping

  • Waving

  • Falling

  • Playing football

A single frame may not clearly distinguish walking from running.

Therefore, the sequence of frames is important.

2. Why is Action Recognition a Sequence Problem?

Consider a walking video:

$$ Frame_1 \rightarrow Frame_2 \rightarrow Frame_3 \rightarrow Frame_4 $$

Each frame contains spatial information, but the order of the frames tells us about movement.

Therefore, action recognition requires temporal sequence understanding.

3. What is an RNN?

RNN stands for Recurrent Neural Network.

It is a neural network designed to process sequential data.

Examples of sequential data:

  • Text

  • Speech

  • Time-series data

  • Sensor data

  • Stock prices

  • Video sequences

RNNs process information step by step while maintaining a hidden state that carries information from previous time steps.

10. Hidden State

Hidden state is the internal representation of information learned from previous inputs.

For a video:

  • Frame 1 → Hidden state 1.

  • Frame 2 → Hidden state 2.

  • Frame 3 → Hidden state 3.

  • Frame 4 → Hidden state 4.

Each hidden state contains information about the sequence processed so far.

An RNN does not store every previous frame separately. It maintains a learned representation that summarizes relevant information.

11. RNN Mathematical Model

The hidden state equation is:

$$ h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h) $$

Where:

SymbolMeaning
$x_t$Current input
$h_t$Current hidden state
$h_{t-1}$Previous hidden state
$W_{xh}$Input-to-hidden weights
$W_{hh}$Hidden-to-hidden weights
$b_h$Bias
tanhActivation function

Output equation:

$$ y_t=W_{hy}h_t+b_y $$

Intuition:

$$ Current\ State=Current\ Input+Previous\ Information $$

12. Numerical Example of RNN

Suppose:

$$ x_t=2,\quad h_{t-1}=3 $$
$$ W_{xh}=0.5,\quad W_{hh}=0.2,\quad b_h=0 $$

Substitute in the hidden-state equation:

$$ h_t=\tanh(0.5(2)+0.2(3)+0) $$
$$ h_t=\tanh(1+0.6) $$
$$ h_t=\tanh(1.6) $$
$$ \boxed{h_t\approx0.922} $$

The new hidden state is passed to the next time step.

16. How is RNN Trained? – BPTT

BPTT stands for Backpropagation Through Time.

It is the training method used for RNNs.

Working:

  1. Unroll the RNN across time steps.

  2. Perform forward propagation for the sequence.

  3. Calculate prediction error using a loss function.

  4. Propagate gradients backward through the time steps.

  5. Calculate gradients for shared weights.

  6. Update weights using an optimizer.

The objective is to reduce prediction error.

17. Vanishing Gradient Problem

During backpropagation, gradients may become extremely small as they move through many time steps.

As a result:

  • Earlier inputs receive very small learning signals.

  • The network struggles to learn long-term dependencies.

  • Important earlier information may not influence later predictions effectively.

Example: An action starts in the first few frames but is completed much later. A traditional RNN may struggle to retain the relevant information.

18. Exploding Gradient Problem

Gradients may become extremely large during backpropagation.

This can cause:

  • Unstable training.

  • Very large weight updates.

  • Difficulty in reaching convergence.

Gradient clipping is one technique used to control exploding gradients.

5.10 – Action Recognition Using LSTM

1. Introduction to LSTM

LSTM stands for Long Short-Term Memory.

It is a special type of Recurrent Neural Network designed to learn long-term dependencies in sequential data.

It is useful when information from earlier time steps is important for understanding something that happens much later.

Example:

A cricket video:

  1. Player picks up a bat.

  2. Player prepares.

  3. Ball approaches.

  4. Player swings the bat.

  5. Ball moves away.

To understand the final action, the model may need to remember what happened in the earlier frames.

2. Why Do We Need LSTM?

Traditional RNNs maintain hidden states and pass information from one time step to another.

However, they can struggle to preserve information from much earlier time steps because of the vanishing gradient problem.

LSTM addresses this limitation using a controlled memory mechanism.

3. What is LSTM?

LSTM is a recurrent neural network architecture that uses gates to control information flow.

It contains three main gates:

  1. Forget Gate

  2. Input Gate

  3. Output Gate

It also maintains:

  • Cell State.

  • Hidden State.

The main idea is:

Forget unnecessary information, store useful information and produce the required output.

4. Cell State and Hidden State

An LSTM maintains two important states.

1. Cell State ($C_t$)

  • Acts as the main memory pathway.

  • Carries information across time steps.

  • Helps preserve important information over longer sequences.

2. Hidden State ($h_t$)

  • Represents the current output/state.

  • Contains information used for the current prediction.

  • Is passed to the next time step.

A useful memory trick:

Cell StateHidden State
Long-term memory pathwayCurrent working/output information
Carries information forwardProduces current output
Updated through gatesControlled by output gate

5. LSTM Cell Architecture

At time $t$, the LSTM receives:

  1. Current input $x_t$.

  2. Previous hidden state $h_{t-1}$.

  3. Previous cell state $C_{t-1}$.

It produces:

  1. Current hidden state $h_t$.

  2. Current cell state $C_t$.

6. The Three Gates of LSTM

This is the most important section in LSTM.

LSTM has three main gates

1. Forget Gate

What old information should be removed?

2. Input Gate

What new information should be stored?

3. Output Gate

What information should be produced as output?

Each gate uses the sigmoid activation function.

$$ \sigma(x)=\frac{1}{1+e^{-x}} $$

Its output ranges between 0 and 1.

  • 0 → Reject or block information.

  • 1 → Allow or retain information.

  • Between 0 and 1 → Partially allow information.

7. Forget Gate

The forget gate decides what information from the previous cell state should be retained or discarded.

Formula:

$$ f_t=\sigma(W_f[h_{t-1},x_t]+b_f) $$

Where:

  • $f_t$ = Forget gate output.

  • $W_f$ = Forget gate weights.

  • $h_{t-1}$ = Previous hidden state.

  • $x_t$ = Current input.

  • $b_f$ = Bias.

Working:

  • Value close to 0 → Mostly forget.

  • Value close to 1 → Mostly retain.

Example:

In a football video, earlier frames show a player walking towards the ball. Later frames show the player kicking the ball.

The forget gate can reduce the influence of less relevant walking information.

8. Input Gate

The input gate determines what new information should be stored in the cell state.

Formula:

$$ i_t=\sigma(W_i[h_{t-1},x_t]+b_i) $$

The LSTM also generates candidate information:

$$ \widetilde C_t=\tanh(W_C[h_{t-1},x_t]+b_C) $$

Where:

  • $i_t$ = Input gate output.

  • $\widetilde C_t$ = Candidate cell information.

  • $W_i,W_C$ = Trainable weights.

  • $b_i,b_C$ = Biases.

Working:

The input gate asks:

"Is this new information important enough to store?"

Example:

In a running video:

Standing → Starting movement → Running.

The input gate controls how much new running-related information is added to memory.

9. Updating the Cell State

This is an extremely important LSTM equation.

$$ \boxed{C_t=f_tC_{t-1}+i_t\widetilde C_t} $$

It contains two parts.

First part:

$$ f_tC_{t-1} $$

Controls how much previous memory is retained.

Second part:

$$ i_t\widetilde C_t $$

Controls how much new information is added.

Therefore:

$$ New\ Memory=Retained\ Old\ Memory+Selected\ New\ Information $$

10. Output Gate

The output gate determines what information should be exposed as the current hidden state.

Formula:

$$ o_t=\sigma(W_o[h_{t-1},x_t]+b_o) $$

The hidden state is calculated using:

$$ \boxed{h_t=o_t\tanh(C_t)} $$

Where:

  • $o_t$ = Output gate.

  • $h_t$ = Current hidden state.

  • $C_t$ = Current cell state.

The hidden state is passed to the next time step.

14. How LSTM Learns Long-Term Dependencies

LSTM uses a cell state that provides a pathway for carrying information across time.

The forget gate controls what information to retain, while the input gate controls what new information to add.

This allows important information from earlier frames to influence later predictions.

Example:

In a cricket video:

  • Early frames: Player picks up a bat.

  • Middle frames: Player prepares.

  • Later frames: Player hits the ball.

LSTM can preserve useful information about the earlier preparation to understand the later action.
