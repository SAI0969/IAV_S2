PART 1: 3.5 – REGION-BASED IMAGE SEGMENTATION

1. Introduction to Image Segmentation

First, understand what image segmentation means.

Image segmentation is the process of dividing an image into different meaningful parts or regions.

For example, imagine a photograph containing:

  • Sky

  • Trees

  • Road

  • Buildings

A computer initially sees the image as thousands or millions of pixels. Image segmentation helps the computer group those pixels into meaningful regions.

What is Region-Based Segmentation?

Region-based segmentation divides an image into regions based on the similarity of pixels.

The basic idea is:

  • Similar pixels → Same region.

  • Different pixels → Different regions.

For example, if 20 neighboring pixels have similar intensity values, they may be grouped into one region.

Important: Region-based segmentation focuses on grouping pixels that belong together, rather than simply detecting boundaries.

2. Why Region-Based Segmentation?

Suppose you have an image of a person standing in front of a wall.

An edge detection technique might identify:

  • Boundary of the person's body.

  • Boundaries of clothes.

  • Shadows.

  • Small changes in texture.

  • Other unnecessary edges.

But our actual requirement might be to identify the entire person as one region.

This is where region-based segmentation is useful.

It answers:

"Which pixels belong together?"

Instead of only asking:

"Where is the boundary?"

3. Region-Based Segmentation Concept

An image can be represented as:

$$ I(x,y) $$

Where:

  • $x$ = Row or horizontal location.

  • $y$ = Column or vertical location.

  • $I(x,y)$ = Intensity or color value of the pixel.

A region is a collection of connected pixels having similar properties.

Similarity can be based on:

  1. Intensity – Brightness of pixels.

  2. Color – Similar RGB values.

  3. Texture – Similar patterns.

  4. Statistical properties – Mean, variance, etc.

Example:

Consider these pixel values:

Plain text50 51 49 52 50 51 49 52 50

All values are approximately 50.

Therefore, these pixels can be grouped into one region.

4. Properties of Good Segmentation

A good segmentation should have three important properties.

4.1 Homogeneity

Homogeneity means pixels inside the same region should be similar.

Example:

Plain text50 51 49 52 50 51 49 52 50

All pixels have similar intensity.

Therefore, they form a homogeneous region.

Remember: Inside one region = Similar pixels.

4.2 Discontinuity Between Regions

Different regions should have significantly different characteristics.

Example:

Plain text50 51 52 | 180 181 179 51 50 51 | 182 180 181

Left side contains values around 50.

Right side contains values around 180.

Therefore, they can be separated into two regions.

Remember: Different regions = Different pixel properties.

4.3 Connectivity

Pixels belonging to the same region should generally be connected to each other.

Example:

Plain text1 1 0 1 1 0 0 0 0

The four 1s are connected.

They form one region.

A collection of isolated pixels should not automatically be treated as one connected region.

5. General Region-Based Segmentation Framework

The general process is:

Input ImagePre-processingSelect Similarity CriterionRegion FormationRegion Splitting / MergingRemove Small or Noisy RegionsFinal Segmented Image

Explanation:

  1. Input image: Give the original image.

  2. Pre-processing: Reduce noise and improve image quality.

  3. Similarity criterion: Decide how to identify similar pixels.

  4. Region formation: Group similar pixels.

  5. Splitting/merging: Improve the regions.

  6. Noise removal: Remove unwanted small regions.

  7. Final output: Obtain the segmented image.

7. REGION GROWING

slideshare.net

Definition

Region growing is a segmentation technique that starts with one or more initial pixels called seed points and gradually adds neighboring pixels that satisfy a similarity criterion.

In simple words:

Start with one pixel → Find similar neighboring pixels → Add them → Continue until no more suitable pixels are available.

8. Basic Idea of Region Growing

Consider this matrix:

Plain text10 11 12 80 82 11 10 13 81 83 12 12 11 82 84 90 91 92 93 94 89 90 91 92 93

We can observe three intensity groups:

  • Values around 10.

  • Values around 80.

  • Values around 90.

Suppose we select a seed in the upper-left region.

The algorithm checks neighboring pixels and adds those with similar intensity.

The upper-left values will form one region.

9. Seed Point

A seed point is the initial pixel from which region growing begins.

Example:

Plain text10 11 12 11 S 13 12 12 11

Here, S represents the seed pixel.

Seed selection methods:

  1. Manual selection – A person selects the pixel.

  2. Automatic selection – Computer selects it.

  3. Known object locations – Select from a known object position.

  4. Local maxima/minima – Select based on intensity peaks or valleys.

  5. Another segmentation method – Use its output to select seeds.

Why is the seed important?

Because region growing starts from that pixel. If the seed belongs to the wrong object, the final segmentation may also be wrong.

10. Region Growing Algorithm

There are six steps.

  1. Select seed point.

  2. Examine neighboring pixels.

  3. Apply similarity criterion.

  4. Add pixels satisfying the criterion.

  5. Continue growing using newly added pixels.

  6. Stop when no neighboring pixels satisfy the condition.

Let's understand with an example.

11. Similarity Criterion

This is one of the most important concepts in region growing.

A common similarity condition is:

$$ |I(p)-I_s|\leq T $$

Where:

  • $I(p)$ = Intensity of the candidate pixel.

  • $I_s$ = Intensity of the seed pixel.

  • $T$ = Threshold.

The threshold determines how much difference is allowed.

Example:

Suppose:

  • Seed intensity = 50.

  • Threshold = 10.

Check a neighboring pixel with intensity 56.

$$ |56-50|=6 $$

Since:

$$ 6\leq10 $$

The pixel is accepted.

Now check a pixel with intensity 70.

$$ |70-50|=20 $$

Since:

$$ 20>10 $$

The pixel is rejected.

Exam tip: If the difference is less than or equal to the threshold, include the pixel. Otherwise, reject it.

14. Region Growing with 4-Connectivity

Consider:

Plain text1 1 0 1 0 1 0 1 1

Start from the top-left 1.

With 4-connectivity, only horizontally and vertically connected 1s are selected.

With 8-connectivity, diagonal 1s can also become connected.

15. Advantages of Region Growing

  1. Simple to understand and implement.

  2. Produces connected regions.

  3. Can use intensity, color and texture.

  4. Works well for homogeneous objects.

  5. Can incorporate domain knowledge through seed selection.

16. Disadvantages of Region Growing

  1. Seed selection: Wrong seeds can produce incorrect segmentation.

  2. Threshold selection: A very small threshold produces many small regions; a very large threshold combines different objects.

  3. Noise sensitivity: Noise can cause unwanted region growth.

  4. Computational cost: Large images and multiple seeds increase computation.

  5. Intensity variation: It may fail when the same object has significantly different intensity values.

17. REGION SPLITTING

slideserve.com

Definition

Region splitting is a segmentation technique that starts with the entire image and divides it into smaller regions whenever a region is not homogeneous.

In simple words:

Large image → Divide into smaller parts → Check similarity → Divide again if needed.

This is the opposite approach to region growing.

18. Basic Idea of Region Splitting

Imagine an image containing:

  • Dark region on the left.

  • Bright region on the right.

Initially, the entire image is considered one region.

The algorithm checks whether the whole image is homogeneous.

If it is not homogeneous, it divides the image into smaller regions.

19. Homogeneity Predicate

A homogeneity predicate is a condition used to decide whether a region is sufficiently uniform.

Let $P(R)$ represent the homogeneity condition for region R.

  • If $P(R)=\text{TRUE}$, the region is homogeneous and is kept.

  • If $P(R)=\text{FALSE}$, the region is not homogeneous and must be split.

Example:

Suppose the maximum allowed intensity difference is 10.

If the region's intensity variation is 5, it can be accepted.

If the variation is 50, it should be split.

20. Numerical Example of Region Splitting

Consider a 4×4 image:

Plain text10 11 | 80 81 11 10 | 82 80 ------+------ 12 11 | 90 91 10 12 | 89 92

Initially, the entire image is one region.

The intensity variation is high because the image contains values around 10, 80 and 90.

Therefore, the algorithm splits it.

Initial image

R1R2R3R4Each quadrant becomes a separate region.

If R1 is homogeneous, it is kept.

If R2 is still heterogeneous, R2 is split again.

This process continues until the regions satisfy the homogeneity condition or reach a minimum size.

21. Quadtree Representation

This is an important concept.

A quadtree is a tree structure in which every region is divided into four smaller regions.

slideshare.net

For example:

  • First, the entire image is one region.

  • Divide it into R1, R2, R3 and R4.

  • If R2 is not homogeneous, divide R2 into another four regions.

  • Continue recursively.

Why is it called a quadtree?

Because each division produces four child regions.

22. Region Splitting Algorithm

  1. Start with the entire image.

  2. Evaluate the homogeneity predicate.

  3. If homogeneous, keep the region.

  4. If not homogeneous, divide it into four subregions.

  5. Evaluate each subregion.

  6. Repeat recursively until the stopping condition is satisfied.

23. Stopping Conditions

Splitting stops when any of these conditions is satisfied:

  1. The region is homogeneous.

  2. The region becomes sufficiently small.

  3. Maximum recursion depth is reached.

24. Advantages of Region Splitting

  • Does not require manually selecting seed points.

  • Systematically examines the entire image.

  • Produces meaningful regions when homogeneity is properly defined.

  • Quadtree structure makes recursive implementation convenient.

25. Disadvantages of Region Splitting

  • May produce too many small regions.

  • Can create artificial boundaries.

  • Homogeneity criterion must be selected carefully.

  • Repeated splitting can increase computational cost.

  • Final regions may need merging.

26. REGION MERGING

slideshare.net

Definition

Region merging is a segmentation technique that combines adjacent regions having similar properties.

In simple words:

Small regions → Compare neighboring regions → Combine similar regions → Larger regions.

It works in the opposite direction to region splitting.

27. Basic Idea of Region Merging

Suppose an image is divided into four regions:

Plain textR1 | R2 ---+--- R3 | R4

If R1 and R2 have similar intensity values and are adjacent, they can be merged.

Similarly, other neighboring regions can be compared.

The process continues until no neighboring regions satisfy the merging condition.

28. Similarity Between Regions

Two regions can be considered similar based on:

  1. Mean intensity.

  2. Color.

  3. Variance.

  4. Texture.

  5. Statistical properties.

A common condition is:

$$ |\mu_1-\mu_2|\leq T $$

Where:

  • $\mu_1$ = Mean intensity of region 1.

  • $\mu_2$ = Mean intensity of region 2.

  • $T$ = Similarity threshold.

If the difference between the mean intensities is less than or equal to the threshold, the regions can be merged, provided they are adjacent.

29. Numerical Example of Region Merging

Suppose four regions have these mean intensity values:

Since $3\leq5$, merge R1 and R2.

30. Region Merging Algorithm

  1. Initialize several small regions.

  2. Identify neighboring regions.

  3. Calculate their similarity.

  4. If the similarity condition is satisfied, merge the regions.

  5. Update the properties of the new region.

  6. Repeat until no neighboring regions satisfy the merging condition.

32. Why Combine Splitting and Merging?

If we only use splitting:

  • The image may be divided into too many small regions.

  • This creates over-segmentation.

If we only use merging:

  • Different regions might incorrectly get combined.

  • This creates under-segmentation.

Combining both methods provides a better balance.

Example:

36. REGION-BASED SEGMENTATION AND NOISE

Noise means unwanted changes or disturbances in image pixel values.

Example:

Plain text50 50 50 50 50 50 90 50 50 50 50 50

Most pixels have intensity 50, but one pixel has intensity 90.

That 90 might be noise.

A region-growing algorithm might incorrectly treat it as a separate region.

Solutions to Noise

  1. Smoothing – Reduces small intensity variations.

  2. Median filtering – Removes unwanted noise while preserving many edges.

  3. Appropriate similarity thresholds – Prevents unnecessary region formation.

  4. Morphological operations – Improve the shapes of segmented regions.

  5. Remove small regions – Eliminate tiny unwanted areas.

37. REGION-BASED SEGMENTATION OF COLOR IMAGES

Region-based segmentation is not restricted to grayscale images.

It can also work with RGB images.

Remember:

RGB means:

  • R = Red.

  • G = Green.

  • B = Blue.

Every pixel has three color values.

For example:

$$ P_1=(100,120,150) $$
$$ P_2=(105,125,145) $$

We can calculate their color distance using:

$$ D=\sqrt{(R_1-R_2)^2+(G_1-G_2)^2+(B_1-B_2)^2} $$

Substituting:

$$ D=\sqrt{(100-105)^2+(120-125)^2+(150-145)^2} $$
$$ D=\sqrt{25+25+25} $$
$$ D=\sqrt{75}=8.66 $$

The two pixels have relatively similar colors.

If the distance is below a selected threshold, they may be grouped into the same region.

Other color spaces:

In practical systems, HSV and Lab color spaces may also be used.

  • HSV = Hue, Saturation, Value.

  • Lab = Lightness and two color-opponent components.

41. EFFECT OF THRESHOLD

Threshold determines how strict or relaxed the similarity condition is.

Suppose:

Seed intensity = 50.

Case 1: Threshold = 5

Accepted intensity range:

$$ 50-5\leq I(p)\leq50+5 $$
$$ 45\leq I(p)\leq55 $$

Only pixels between 45 and 55 are accepted.

Strict condition

Result: Smaller region.

Case 2: Threshold = 30

$$ 50-30\leq I(p)\leq50+30 $$
$$ 20\leq I(p)\leq80 $$

More pixels are accepted.

Relaxed condition

Result: Larger region.

Case 3: Threshold is too large

Different objects may also satisfy the similarity condition.

They may incorrectly become one region.

Important conclusion:

  • Small threshold → Smaller regions.

  • Large threshold → Larger regions.

  • Extremely large threshold → Different objects may merge.

42. REGION GROWING VS THRESHOLDING

These two concepts are often confused.

Thresholding

Thresholding separates pixels based mainly on their intensity values.

For example:

$$ I(x,y)>T $$

If the pixel intensity is greater than the threshold, it may be classified as foreground.

Otherwise, it may be classified as background.

Thresholding does not inherently require spatial connectivity.

Region Growing

Region growing uses:

  1. Seed.

  2. Neighborhood.

  3. Similarity.

  4. Connectivity.

It checks whether a pixel is similar and connected to the growing region.

ThresholdingRegion Growing
Based mainly on intensityBased on similarity and connectivity
Does not require a seedRequires a seed
Does not inherently require connectivityUses connectivity
Classifies pixels based on thresholdGrows connected regions

Example:

Imagine two separate objects having the same intensity.

Thresholding may select both objects because their intensity values are similar.

Region growing starting from one object can select only the connected region around its seed.

43. REGION GROWING PSEUDOCODE

Pseudocode means writing the logical steps of an algorithm in a simple programming-like format.

Your document gives the following algorithm:

Plain textChoose seed pixel Create empty region R Put seed into R while there are neighboring pixels: select neighboring pixel p if p satisfies similarity criterion: add p to R examine p's neighbors else: reject p return R

Explanation

  • Choose seed: Select starting pixel.

  • Create empty region: Prepare a region to store selected pixels.

  • Put seed into R: Add the starting pixel.

  • While: Continue checking neighboring pixels.

  • If: Check whether the pixel is similar.

  • Add: Include accepted pixels.

  • Reject: Ignore pixels that do not satisfy the condition.

  • Return: Output the final region.

For multiple objects:

  1. Choose multiple seeds.

  2. Grow each seed independently.

  3. Resolve overlapping regions.

  4. Return the final segmentation.

  9. Final segmentation – Produce the final result.

45. OVERALL ADVANTAGES OF REGION-BASED SEGMENTATION

  1. Produces connected regions.

  2. Uses spatial information.

  3. Can use intensity, color and texture.

  4. Works well for relatively homogeneous objects.

  5. Can incorporate domain-specific knowledge.

  6. Region growing is intuitive and easy to implement.

  7. Splitting provides systematic image decomposition.

  8. Merging can reduce over-segmentation.

46. OVERALL LIMITATIONS

  1. Sensitive to noise.

  2. Parameter selection is important.

  3. Region growing depends on seed selection.

  4. Large images may require significant computation.

  5. Objects with non-uniform intensity can be difficult to segment.

  6. Poor similarity criteria can cause under-segmentation.

  7. Poorly chosen criteria can cause over-segmentation.

48. EXAM-ORIENTED DEFINITIONS

Learn these definitions because they are useful for short-answer questions.

Region-Based Segmentation: It divides an image into connected regions whose pixels satisfy a specified homogeneity or similarity criterion.

Region Growing: It starts from one or more seed pixels and iteratively adds neighboring pixels that satisfy a similarity criterion.

Region Splitting: It starts with the entire image and recursively divides non-homogeneous regions into smaller regions.

Region Merging: It combines adjacent regions whose properties satisfy a specified similarity criterion.

Homogeneity Predicate: It is a rule used to determine whether a region is sufficiently uniform.

PART 2: 3.6 – K-MEANS CLUSTERING WITH IMAGE SEGMENTATION

Now let's move to your second document.

This topic is connected to region-based segmentation, but the approach is different.

The main concept is K-Means Clustering.

1. What is K-Means?

K-Means is an unsupervised machine learning algorithm used to divide data points into K different groups called clusters.

Let's understand the words.

  • K = Number of clusters we want.

  • Means = Average of the data points in each cluster.

For example, suppose you have 10 students and want to divide them into three groups based on their marks.

K-Means groups students with similar marks together.

In image segmentation, instead of students, we use pixels.

Important: K-Means is unsupervised because we do not provide predefined labels for every pixel. The algorithm discovers groups based on similarity.

2. K-Means in Image Segmentation

Every pixel in an image is treated as a data point.

Pixels with similar colors or intensity values are grouped into the same cluster.

For example, imagine an image containing:

  • Dark pixels.

  • Medium-brightness pixels.

  • Bright pixels.

K-Means can divide them into three clusters.

For a grayscale image, each pixel is represented by its intensity value.

For an RGB image, each pixel is represented by three values:

$$ Pixel=(R,G,B) $$

Where:

  • R = Red.

  • G = Green.

  • B = Blue.

13. HOW DISTANCE WORKS FOR RGB

This is very important for numerical questions.

In grayscale, we calculate the difference between two intensity values.

In RGB, we calculate the Euclidean distance between three color values.

Formula:

$$ D=\sqrt{(R_1-R_2)^2+(G_1-G_2)^2+(B_1-B_2)^2} $$

Numerical Example

Suppose a pixel is:

$$ P=(100,120,150) $$

And the centroid is:

$$ C=(110,125,145) $$

Calculate:

$$ D=\sqrt{(100-110)^2+(120-125)^2+(150-145)^2} $$
$$ D=\sqrt{(-10)^2+(-5)^2+(5)^2} $$
$$ D=\sqrt{100+25+25} $$
$$ D=\sqrt{150} $$
$$ \boxed{D\approx12.25} $$

The algorithm performs this calculation against every centroid.

The pixel is assigned to the centroid having the smallest Euclidean distance.

15. THE MOST IMPORTANT IDEA OF K-MEANS

Students often get confused with the equations.

But the basic concept is simple.

Every pixel asks:

"Which centroid am I closest to?"

Then every centroid asks:

"What is the average value of the pixels assigned to me?"

These two operations continue repeatedly.

16. THE TWO MOST IMPORTANT STEPS

There are only two fundamental operations in K-Means.

1. Assignment Step

Assign each data point to its nearest centroid.

2. Update Step

Calculate the mean of all data points belonging to each cluster and update its centroid.

Repeat these two steps until convergence.

17. MATHEMATICAL FORM OF K-MEANS

There are two important mathematical operations.

A. Assignment Formula

$$ C(x_i)=\arg\min_j\|x_i-\mu_j\|^2 $$

Don't get scared by this formula!

Meaning:

  • $x_i$ = Current data point or pixel.

  • $\mu_j$ = Centroid of cluster j.

  • $C(x_i)$ = Cluster assigned to the pixel.

  • $\arg\min$ = Choose the value that gives the minimum distance.

In simple words:

Find the centroid having the smallest squared distance from the pixel.

B. Update Formula

$$ \mu_j=\frac{1}{|C_j|}\sum_{x_i\in C_j}x_i $$

Meaning:

  • $\mu_j$ = New centroid.

  • $C_j$ = All pixels belonging to cluster j.

  • $|C_j|$ = Number of pixels in that cluster.

  • Sum = Total of all pixel values.

In simple words:

Calculate the average of all pixels belonging to that cluster.

18. WHY DO WE SQUARE THE DISTANCE?

K-Means generally uses squared Euclidean distance instead of ordinary Euclidean distance.

For example:

Normal distance:

$$ D=\sqrt{(x-c)^2} $$

Squared distance:

$$ D^2=(x-c)^2 $$

Why do we square it?

  1. Avoids calculating square roots.

  2. Penalizes large errors more strongly.

  3. Provides a convenient mathematical optimization problem.

Important point:

For deciding which centroid is closest, the square root is unnecessary because square root is an increasing function for non-negative values.

For example:

  • Distance 2 has square 4.

  • Distance 5 has square 25.

The smallest distance is still the smallest squared distance.

Therefore, we can compare squared distances directly.

19. K-MEANS OBJECTIVE FUNCTION

The objective of K-Means is to minimize the total squared distance between every pixel and its assigned centroid.

The objective function is:

$$ J=\sum_{j=1}^{K}\sum_{x_i\in C_j} \|x_i-\mu_j\|^2 $$

This is called:

Within-Cluster Sum of Squares (WCSS).

Let's understand it.

  • WCSS = Within-Cluster Sum of Squares.

  • Within-cluster = Inside each cluster.

  • Sum of squares = Add all squared distances.

In simple words:

K-Means tries to keep pixels as close as possible to their assigned centroids.

Small numerical example

Suppose one cluster contains:

Plain text10, 12, 14

Its mean is:

$$ \mu=\frac{10+12+14}{3}=12 $$

Squared distances:

$$ (10-12)^2=4 $$
$$ (12-12)^2=0 $$
$$ (14-12)^2=4 $$

Therefore:

$$ WCSS=4+0+4 $$
$$ \boxed{WCSS=8} $$

The objective of K-Means is to minimize this value across all clusters.
